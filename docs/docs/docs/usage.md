# Manual de Uso do Sistema

## Fluxo do Paciente
1. Acesse a página inicial e escolha a data e horário desejados.
2. Informe nome, e-mail e telefone para confirmar o agendamento.
3. Exatamente 24 horas antes, responda ao lembrete recebido para confirmar a presença.

## Fluxo da Recepcionista
1. Acesse o painel restrito da clínica.
2. Verifique a lista de "Pendentes de Confirmação" em destaque.
3. Realize o contato telefônico com os pacientes não confirmados e atualize o status no painel.
