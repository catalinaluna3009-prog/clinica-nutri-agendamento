# Guia de Instalação do Sistema

## Pré-requisitos
- Node.js versão 18 ou superior.
- Banco de dados PostgreSQL configurado.

## Passo a Passo
1. Clone o repositório para sua máquina local.
2. Execute `npm install` no terminal para baixar as dependências.
3. Crie um arquivo `.env` na raiz com as credenciais do banco de dados.
4. Execute `npm run dev` para iniciar a aplicação em modo de desenvolvimento.
